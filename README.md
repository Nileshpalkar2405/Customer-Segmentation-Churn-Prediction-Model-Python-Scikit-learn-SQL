# Customer-Segmentation-Churn-Prediction-Model-Python-Scikit-learn-SQL
Customer churn analysis &amp; intelligence pipeline using SQL, Python &amp; Pandas — identified churn drivers (escalations correlate 0.77 with churn), segmented customers by plan/risk, and flagged $73.9K in at-risk revenue. Includes EDA, feature engineering, and Matplotlib/Seaborn visualizations.
